# Быстрый старт: картинка на CD-RW (Linux)

Как напечатать картинку на диске с готовым пресетом. Замерять ничего не нужно.

**Подходит для** CD-RW Infodisc, ATIP `97:25/31`, 359848 секторов. Проверить диск:
```bash
cdrecord -v dev=/dev/sr0 -atip | grep -E 'Manufacturer|ATIP start'
```
Совпадение ATIP не гарантирует совпадение геометрии. Пресет проверен на трёх дисках одного комплекта и приводе Optiarc AD-5240S. На других болванках снова могут появиться кольца, см. [раздел про другие диски](#другие-диски).

## Установка

Нужны .NET 10 SDK, `cdrecord`, а для шаблонов ещё Python 3, numpy и Pillow.

```bash
git clone -b cd-cubic-pitch https://github.com/Usell2021/DiscImageStudio.git
cd DiscImageStudio
python3 tools/CdRotationProbe/make_template.py
```

Последняя команда один раз собирает шаблоны в `tools/CdRotationProbe/template/`.

## 1. Подготовить картинку

Холст 2400×2400 px, центр холста совпадает с центром диска. 1 мм равен примерно 21 px.

| Зона | От центра, px | От центра, мм | Что с ней |
|---|---|---|---|
| Отверстие | 0–520 | 0–24,9 | Не печатается |
| Надёжная зона | 553–1169 | 26,5–56 | Для лиц и текста |
| Кольцо целиком | 520–1200 | 24,9–57,5 | Печатается |
| Углы холста | больше 1200 | больше 57,5 | За краем диска |

**В редакторе (GIMP, Krita, Photoshop):**
1. Откройте `tools/CdRotationProbe/template/disc-overlay-2400.png`, это верхний слой с разметкой.
2. Положите фото слоем под него и подгоните.
3. Скройте шаблон и экспортируйте PNG 2400×2400. Если не скрыть, линии разметки напечатаются.

**В ffmpeg:** рецепты есть в [README инструмента](tools/CdRotationProbe/README.md#ffmpeg).

**Что лучше работает:**
- Лица от 400 px, подальше от края.
- Линии от 10–12 px, текст высотой от 50 px.
- Крупные контрастные формы. Полутона сильно зависят от угла света, тёмные и шумные снимки выходят хуже всего.
- Отверстие лучше ставить на пустое место. В него же можно спрятать ненужный объект.

## 2. Собрать трек

Нужен файл около 850 МБ. `--tone-dither 1` включает полутона, для чисто чёрно-белой картинки его нужно убрать.

```bash
dotnet run --project src/DiscImageStudio.Cli -c Release -- \
  cd-generate --input картинка.png --output track.wav \
  --preset noname-cd-rw-infodisc --tone-dither 1
```

## 3. Посмотреть результат без записи

Отверстие и края на превью просто белые.

```bash
dotnet run --project src/DiscImageStudio.Cli -c Release -- \
  cd-preview-track --track track.wav --output preview.png \
  --preset noname-cd-rw-infodisc --size 1000
```

## 4. Проверить диск

Новому диску может понадобиться около минуты, чтобы привод его распознал.

```bash
cdrecord dev=/dev/sr0 -minfo | grep 'disk status'
```

| Ответ | Что значит |
|---|---|
| `empty` | Диск пустой, переходите к шагу 6 |
| `complete` | Диск записан, сначала сотрите его |
| `No disk` | Подождите минуту и повторите. Если не помогло, проверьте, что диск лежит блестящей стороной вниз и защёлкнут на шпинделе |

## 5. Стереть, если диск записан

Запись будет уничтожена. Сначала убедитесь, что на диске нет ничего нужного.

```bash
cdrecord dev=/dev/sr0 blank=fast
```

## 6. Записать

Около 6 минут, диск не вынимать. Нужен именно `-dao`: трек занимает диск до самого конца.

```bash
cdrecord dev=/dev/sr0 speed=16 -dao -audio track.wav
```

Смотреть под одной яркой лампой, медленно наклоняя диск. В CD-плеере такой диск даст громкий шум вместо музыки.

## Картинка и MP3 на одном диске

Файл кладётся во внешнюю часть диска, а кольцо под картинку сокращается примерно настолько, сколько занимает файл. Диск с MP3 играет на компьютере и в плеерах, которые читают MP3.

```bash
mkdir files && cp музыка.mp3 files/
dotnet run --project src/DiscImageStudio.Cli -c Release -- \
  cd-generate --input картинка.png --output disc.iso --data-dir files \
  --volume-label MY_DISC --file-position outer \
  --preset noname-cd-rw-infodisc --tone-dither 1
cdrecord dev=/dev/sr0 speed=16 -dao -data disc.iso
```

**Экспериментально:** такой диск записался без ошибок, файл на нём виден с правильным именем и размером. Но побайтное совпадение файла с оригиналом и положение картинки пока не подтверждены.

## Другие диски

Для записанного диска есть проверка, только чтением, около двух минут:
```bash
cd tools/CdRotationProbe
python3 check_disc.py --preset noname-cd-rw-infodisc
```
Если ошибка меньше 5°, пресет подходит. Если больше 30°, будут кольца и нужен свой замер, он описан в [README инструмента](tools/CdRotationProbe/README.md).

`check_disc.py` пока проверен на записанных ранее данных, но ещё не запускался целиком на записанном диске.
